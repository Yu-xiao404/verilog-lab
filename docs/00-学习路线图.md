## 0. 北极星目标

用 1～2 年的碎片时间，**独立做出一个能运行自己程序的 RISC-V 小处理器**：
先在仿真里跑通 → 再上 FPGA 点亮真实硬件 →（可选）用开源流程体验一次流片。
达到「数字 IC 前端设计 / 验证」入门到准初级水平，并清楚自己更适合哪条岗位方向。

关键认知（来自「一生一芯」）：**处理器设计 ≠ 写 RTL**。完整链路是
架构设计 → 逻辑设计(RTL) → 功能验证 → 性能验证 → 电路评估 → 物理设计。
我们现在练的 RTL + testbench + 参考模型 + Git/CI，正是其中「逻辑设计 + 功能验证」
这两个最适合 CS 背景切入的环节，方向从第一天就是对的。

## 1. 总览：八级阶梯（自底向上搭积木，坡度刻意拆平）

| 级别 | 名称 | 状态 | 对应仓库内容 |
|---|---|---|---|
| L0 | 环境与工具链 | ✅ 已完成 | WSL + iverilog + GTKWave + Make + Git/GitHub/Actions CI |
| L1 | 组合逻辑积木 + 自检测试台 | ✅ 基本完成 | 01-adder / 02-mux / 04-decoder / 05-and / 06-xor / 07-fulladder / 08-magcmp |
| L2 | 时序逻辑与状态机 | ▶ 下一步 | 03-counter 吃透、09 时序 testbench、有限状态机 FSM、流水灯小系统 |
| L3 | CPU 数据通路零件 | 未开始 | 寄存器堆 regfile、ALU、总线/多路器、ROM/RAM、时钟分频 |
| L4 | 软件先行：迷你 RISC-V 模拟器（CS 优势关） | 未开始 | 用 C/Python 写「取指→译码→执行→更新 PC」状态机 |
| L5 | 单周期 RISC-V 小核 | 未开始 | 用 L3 零件拼 CPU，用 L4 模拟器做参考模型做差分测试 |
| L6 | 多周期 → 流水线 | 未开始 | 数据/控制冒险、转发(forwarding)、冒泡(stall)，五级流水线 |

**横切能力（贯穿每一级，不是单独一级）**：Git/CI 版本管理、波形调试、
费曼复述、每个项目写 README、HDLBits 日常刷题保持「手感」。

## 2. 每级的「毕业标准」（达到再进下一级，不追快）

### L1 组合逻辑 + 测试台（✅ 已毕业标准）
- 能说清组合逻辑「无记忆、输入变输出立刻变」，会用 `assign` 和 `always @(*)`。
- 能独立写出五段式 testbench：声明 → 例化 DUT → 造激励 → 独立参考模型对拍 → 汇总判卷。
- 理解位宽 `[n-1:0]`、字面量、`!==` 四态比较、`$fatal(1)` 驱动 CI 红绿。
- 现状：8 个实验全绿、亲手 push、云端 CI success。**已达成。**

### L2 时序逻辑与状态机（▶ 当前）
- 理解时钟 `clk`、上升沿 `posedge`、寄存器「记住上一拍」、同步/异步复位、使能。
- 会区分：组合用阻塞 `=`、时序用非阻塞 `<=`。
- **会自己写时序 testbench**：在测试台里造周期时钟、按拍施加复位/使能、逐拍核对状态。
- 会写有限状态机 FSM（例如「序列检测」「红绿灯」「按键消抖」）。
- 毕业项目：用 counter + decoder 拼一个「流水灯」，自己写 testbench 验证节拍。

### L3 CPU 数据通路零件
- 寄存器堆：同一时钟读两端口、写一口（就是 02-mux/04-decoder 的组合升级）。
- ALU：把加法器、比较器、与或异或打包成一个「按操作码选择运算」的部件。
- 存储器：用 `reg [ ] mem [ ]` 建 ROM/RAM，理解同步读写下的波形。
- 毕业标准：每个零件都有独立 testbench 全绿，能在一张框图上讲清它们怎么连线。

### L4 软件先行：迷你 RISC-V 模拟器（★ 为 CS 背景量身定做的巧思）
- 为什么先写软件：「一生一芯」和 Berkeley CS152 都让学生**先用 C 写指令集模拟器，
  再写硬件**。用你已经会的编程语言，先彻底搞懂 CPU 怎样一步一步执行指令，
  之后写 RTL 只是把同一套逻辑「翻译」成电路，门槛骤降。
- 任务：实现 RV32I 的一小撮指令（先加、减、与或、立即数、跳转，约 10 条），
  能手工喂几条机器码、看到寄存器和 PC 正确变化。
- 毕业标准：能向小白讲清「取指、译码、执行、写回、更新 PC」一轮发生了什么。

### L5 单周期 RISC-V 小核
- 把 L3 零件按数据通路图拼成完整单周期 CPU；控制器用 FSM/组合逻辑产生控制信号。
- **验证巧思**：把 L4 的模拟器当「参考实现」，让 RTL CPU 和它对拍（差分测试），
  这正是工业界功能验证和「一生一芯」DiffTest 的最小雏形——你从 L1 就在练这套。
- 毕业标准：跑通十几条指令构成的小程序，仿真波形与模拟器结果逐条一致。

### L6 多周期 → 流水线
- 先做多周期（一条指令分几拍），再做五级流水线（IF/ID/EX/MEM/WB）。
- 解决冒险：数据冒险用转发，控制冒险用冒泡/预测；亲眼看到流水线如何提速。
- 毕业标准：能说清单周期 vs 流水线在哪变快、快多少（「一生一芯」答辩级问题）。

### L7 系统与落地（真实感来源）
- 写一段自己的 RISC-V 汇编小程序在 CPU 上跑出可见结果。
- 上 FPGA 开发板：点灯、数码管、按键，让设计变成真实跳动的硬件。
- 用 Yosys 把 RTL 综合成门级网表，看懂面积/层级；可选 TinyTapeout 提交设计体验流片。

## 3. 贯穿始终的 6 条学习方法（名校与前沿计划的共性）

1. **项目带知识，先完成再完美（KISS）**：每级先做出能跑的最小东西，再迭代增强；
   「一生一芯」从只有 3 条指令的处理器起步，复杂系统是长出来的，不是一次设计对的。
2. **脚手架逐步撤除**：填空题 → 补整份 → 从零写，和学骑车拆辅助轮一个道理。
3. **红绿循环**：先故意改坏看红灯/报错，再改回看绿灯，错误信息是最好的教材。
4. **验证驱动、软件思维管硬件**：HDL 也是代码，用 testbench、参考模型、Git、CI
   去管理和测试它——这是你作为 CS 学生相对微电子科班的独特优势。
5. **费曼输出 + 高频回看全局地图**：每学一个部件就用大白话讲一遍；每级回来看本图，
   解决「零件学了一堆、看不到整栋房子」的雾里看花感（整体感在 L5 拼 CPU 时收敛）。
6. **独立排错**：报错先自己读、定位、复述，再求助；让 AI 帮忙时要求它讲清「为什么」，
   拿回来自己核对，不做复制粘贴的搬运工。

## 4. 主食与辅食（避免只啃一份材料）

- **主食（主线，必做）**：本 verilog-lab 仓库，一级一级往上盖，每个实验都 push + CI。
- **辅食 A · 保持手感**：HDLBits（硬件界的 LeetCode，浏览器即写即反馈），每天 3～5 题，
  不求多，用来补「语法/小电路」的单词量。
- **辅食 B · 补理论**：MIT 6.004《Computation Structures》（门→组合/时序→FSM→CPU
  的层级讲得最清楚）；Berkeley CS152（C 模拟器→Verilog→FPGA→流水线，和本路线同构）。
- **辅食 C · 远景地图**：「一生一芯」公开讲义（ysyx.oscc.cc），不要求跟做，
  用来知道「工业级处理器还要走多远」，开阔专业世界观。

## 5. 方向分叉（到 L5 之后再选，现在不用纠结）

- **数字验证（行业缺口最大、和编程最像）**：SystemVerilog → UVM 方法学 → 覆盖率/约束随机。
- **数字设计 / 处理器架构（最有成就感）**：继续流水线、Cache、总线、SoC，可对接考研/科研。
- **FPGA / 硬件加速（最快落地）**：板级调试、时序约束、接口协议、算法加速。
- 模拟 / 射频 / 器件 / 工艺方向需要回头补半导体物理与模电，不在本 CS 友好路线内，暂不碰。

## 6. 开源工具链地图（一台电脑就能走很远）

- 现在：Icarus Verilog（仿真）+ GTKWave（波形）+ Make + Git/GitHub Actions。
- 进阶：Verilator（lint 与高性能仿真）、cocotb（用 Python 写 testbench）。
- 综合/上板：Yosys（RTL→门级网表）、nextpnr（布局布线）、Lattice/Intel FPGA 免费工具。
- 流片体验：TinyTapeout + SkyWater 开源 PDK / OpenLane。
