# 半导体与数字芯片设计扫盲（写给计算机专业的你）

这篇文档只讲四件事：**芯片是什么、半导体行业怎么分工、代码怎么变成硅片、本仓库处于哪一步。** 读完你会知道每个工具在干什么、为什么要按这个顺序学。

---

## 一、芯片到底是什么

- **半导体**：导电能力介于导体和绝缘体之间的材料，现代芯片的基底是硅（Si）。在纯硅里掺入微量其他元素，可以造出两种受控开关：NMOS / PMOS，合称 **CMOS 晶体管**。
- 一个 CMOS 晶体管本质上是一个**受电压控制的电子开关**：栅极给电就导通、不给电就断开。今天一颗手机 SoC 里有上百亿个这样的开关。
- **数字芯片**只关心两种电平：高电平 = 1，低电平 = 0。用晶体管搭出「与/或/非」门，门搭出加法器/寄存器，加法器和寄存器搭出 CPU——和你在《数字逻辑》课上学的层级一致，只是物理上它是刻在硅片上的。
- 与之并列的是**模拟芯片**（处理连续信号，如运放、电源管理、射频），本仓库先聚焦数字方向。

## 二、半导体行业的分工链条

做一颗现代芯片不是一家公司全包，行业是分层的：

| 环节 | 干什么 | 典型公司 | 开源世界的对应物 |
|---|---|---|---|
| **EDA** | 设计芯片用的软件工具（仿真、综合、版图） | Synopsys、Cadence、Siemens EDA | Yosys、OpenROAD、KLayout、Verilator、iverilog |
| **IP 核** | 可复用的设计模块（CPU 核、接口控制器） | ARM、Imagination | RISC-V 核：PicoRV32、SERV、Ibex |
| **Fabless（设计）** | 只设计、不建厂 | 英伟达、高通、AMD、华为海思 | 开源芯片社区、TinyTapeout |
| **Foundry（代工制造）** | 拿设计图纸在晶圆厂造芯片 | 台积电、三星、中芯国际 | SkyWater（开放 130nm 工艺 SKY130） |
| **OSAT（封测）** | 封装、测试 | 日月光、长电科技 | — |
| **PDK（工艺设计包）** |  Foundry 提供给设计方的「制造说明书」：晶体管参数、单元库、设计规则 | 各家 Foundry 私有且保密 | google/skywater-pdk（2020 年起完全开放） |

**为什么开源芯片是当下的时代机会**：在 2020 年 SKY130 开放之前，PDK 和 EDA 都极其昂贵，个人根本不可能触碰「从代码到芯片」的完整链路。现在这条链路全免费、可复算，还能通过 TinyTapeout / MPW 多项目晶圆计划以很低成本真实流片；叠加 RISC-V（开放指令集，不受授权限制）的浪潮，这正是计算机背景的人切入半导体最低的一道门槛。

## 三、代码怎么变成硅片：和软件开发的一一对应

```
你熟悉的软件开发                数字芯片设计
───────────────              ──────────────────────────────
写高级语言源码 (C/Java)   →    写 RTL 描述 (Verilog/SystemVerilog)
编译前先跑单元测试        →    仿真 (Simulation)：testbench 验证行为
编译成机器码 (gcc)        →    综合 (Synthesis, Yosys)：RTL → 门级网表
链接 + 装载到内存地址     →    布局布线 (P&R, OpenROAD)：门摆到硅片上并连线
静态检查 / sanitizer      →    DRC/LVS/STA：设计规则、版图一致性、时序检查
可执行文件                →    GDSII：版图文件，芯片的“最终二进制”
发布上线（出 bug 能热修） →    流片 Tapeout（一次几十万起，且无法打补丁）
```

几个关键概念，用软件类比解释：

- **RTL（Register Transfer Level，寄存器传输级）**：用 Verilog 描述「数据在寄存器之间、在时钟拍之间如何流动和运算」。注意：Verilog **看起来像 C 语言，但它描述的是并行硬件**——每行 `assign`/`always` 都是一块同时工作的电路，不是顺序执行的指令，这是新手最需要扭转的思维。
- **仿真（Simulation）**：在电脑上用软件模拟电路随时间的行为。`iverilog`/`Verilator` 就是仿真器，相当于硬件的「解释执行器」。**仿真不制造任何东西，只验证逻辑对不对**，所以零成本、可反复跑，是你现在的主战场。
- **testbench（测试台）**：专门给仿真器用、不会被综合成电路的代码，负责产生时钟/复位/输入信号并检查输出，就是硬件单元测试。
- **综合（Synthesis）**：把 RTL「翻译」成与门、或门、触发器组成的网表（netlist），类似编译。综合器还会报告面积、最高频率。
- **布局布线（Place & Route）**：决定每个门在硅片上的物理位置、金属线怎么连，类似链接和地址分配，产物是 **GDSII 版图**。
- **PDK**：Foundry 给的制造说明书，告诉 EDA 工具「这个工艺下晶体管长什么样、线能多细、规则是什么」。开源流程用 SKY130。
- **流片（Tapeout）**：把 GDSII 交给晶圆厂制造。因为造一次又贵又慢且**没法补丁**，所以行业把「仿真验证」看得极重——这也是为什么本仓库从第一天就要求每个电路配自检测试和 CI。

## 四、Verilog 的两类电路：本仓库的学习顺序

数字电路只有两种构件，本仓库按先易后难排列：

1. **组合逻辑**（lab 01、02）：无时钟、无记忆，输出只看当前输入，像纯函数。
   - `assign x = ...;` 或 `always @(*) case`
2. **时序逻辑**（lab 03）：有触发器、有记忆，只在时钟沿更新，像有状态对象。
   - `always @(posedge clk)` + 非阻塞赋值 `<=`

掌握这两者 + 状态机，你就具备了描述任何数字电路的语法基础；剩下的是架构问题（比如怎么搭一颗 CPU）。
