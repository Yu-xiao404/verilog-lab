# Lab 03 — 8 位计数器（时序逻辑）

## 这个电路在干什么

每个时钟上升沿：复位有效则清零，否则 `en=1` 时计数 +1、`en=0` 时保持。它是**时序逻辑**：电路里第一次出现「记忆」——靠触发器（Flip-Flop）把值存住。

**在真实芯片里**：CPU 的程序计数器 PC 本质就是个复杂计数器；定时器、PWM、UART 波特率发生器（把 50MHz 系统时钟分频到 115200 波特）都是计数器的变体。

## 文件

- `counter.v`：`always @(posedge clk)` + 非阻塞赋值 `<=`，时序逻辑的标准范式。
- `tb_counter.v`：自己造时钟，分三段测：复位值 → 连续 10 拍递增 → en 拉低后冻结。

## 学习要点

1. **时钟沿触发**：`@(posedge clk)` 表示只有上升沿那一刻才更新值，两次沿之间输入怎么变都不影响输出——这就是「同步时序电路」。
2. **非阻塞赋值 `<=`**：所有右端先统一采样、左端在沿后统一更新，模拟了「触发器同时翻转」的物理事实。时序逻辑里写成 `=` 会导致仿真行为不符合硬件，属于经典错误，建议故意改一次看测试怎么挂。
3. **同步/异步复位、高/低有效**：本实验用同步 + 低有效（`rst_n`，命名里的 `_n` = negative）。另一种是 `@(posedge clk or negedge rst_n)` 的异步复位，两种风格业界都在用，要能看懂。
