# Lab 01 — 4 位加法器（组合逻辑）

## 这个电路在干什么

计算 `{cout, sum} = a + b + cin`：两个 4 位二进制数相加，`sum` 是 4 位和，`cout` 是溢出的进位。它是**组合逻辑**：输入一变，经过门延迟后输出立刻变，不需要时钟。

**在真实芯片里**：CPU 的 ALU 做加减、取指令时 PC+4、Cache 地址计算，底层都是加法器；更复杂的乘法器也是「加法 + 移位」堆出来的。

## 文件

- `adder4.v`：电路本体。注意 `{cout, sum}` 的**位拼接**技巧——拼成 5 位刚好容纳进位。
- `tb_adder4.v`：自检测试台，穷举全部 256 组输入，用整数加法当「软件参考模型」比对。

## 学习要点

1. `assign` 连续赋值描述组合逻辑；`#1` 是仿真时间（1ns），不是延时函数。
2. `!==` 是「 case 不等」：连 `x`（未知态）/`z`（高阻态）也会判为不同，自检更严格。
3. `$fatal(1)` 让仿真以非零码退出——CI 红灯的原理就在这里。
