# Lab 04 — 2-4 译码器（组合逻辑，第一个由你自己写的实验）

## 这个电路在干什么

译码器（Decoder）是多路选择器的"镜像"：输入一个编号 `sel`，把对应那一根输出线拉高（one-hot，独热码），其余拉低；`en` 是总使能，关掉时全部输出 0。

真值表：

| en | sel | y[3:0] |
|----|-----|--------|
| 0  | ×   | 0000   |
| 1  | 0   | 0001   |
| 1  | 1   | 0010   |
| 1  | 2   | 0100   |
| 1  | 3   | 1000   |

**在真实芯片里**：地址译码（选中某块内存/某个外设）、指令操作码译码、片选信号生成，CPU 和总线里到处都是。它和 MUX 互为逆操作，是组合逻辑两大最基础结构。

## 你的任务

自己编写 `decoder.v`（本目录下，测试台已由老师写好，不要改）：

- 模块名必须是 `decoder`，端口：`input [1:0] sel`、`input en`、`output [3:0] y`
- 推荐模仿 `labs/02-mux/mux4.v` 的 `always @(*) + case` 结构：
  先判断 en，en=0 给 `4'b0000`；en=1 再用 case 按 sel 给 one-hot 值，别忘 `default`。
- `4'b0001` 是 4 位二进制字面量；one-hot 就是"只有一个 1"。
